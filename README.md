# MFTracker-Web 💸

This repository contains the source code and documentation for a Personal Finance & Expense Tracker App. It is developed as a showcase of my front-end development capabilities and integrated into my digital portfolio.

This project emphasizes core web fundamentals (*native skills*):
* **Pure Semantic HTML:** Structuring clean, accessible, and standardized web documents, complete with tailored metadata and specific attributes for structural testing.
* **Modern Native CSS:** Designing fully adaptive and responsive layouts across devices using Flexbox and Grid. It implements a custom UI design system consistent with my personal brand, without relying on third-party CSS frameworks.
* **Vanilla JavaScript:** Implementing complex interactivity logic, direct DOM manipulation, Web Storage API (`localStorage`) for data persistence, dynamic search/filtering, and Custom Events for seamless UI state management with zero external libraries.

### 💻 Local Development
To clone and run this project locally, run the following command in your terminal:

```bash
git clone git@github.com:ansyahmf/MFTracker-Web.git
```

No build tools or package managers are required. Simply open `index.html` in your preferred web browser or use a local development server like VS Code Live Server.
